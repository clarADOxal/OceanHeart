🗺️ Générer votre carte mondiale

Procédure à suivre sur MapChart.net :
  1. Cliquez sur le bouton "📋 Copier le code" en bas de cette fenêtre.
  2. Ouvrez le site MapChart.net (World Map).
  3. Dans la colonne de gauche, cherchez l'icône de dossier nommée "Save - Upload".
  4. Cliquez sur le bouton "Upload Map Configuration".
  5. Collez (Ctrl+V) le code dans la zone qui vient de s'ouvrir et validez.

Note : Les pays seront colorés selon 3 niveaux d'intensité (Orange <10, Rouge <100, Bordeaux >100).
